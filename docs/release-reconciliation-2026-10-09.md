## Причина

Zoom-доработки завершались в отдельном checkout `AppData/Local/CodexWork/nafanya-bot` (main, 3d24c56). Основной checkout `OneDrive/Desktop/AI-ПН` содержал Telegram-исправления, но не Zoom-доработки. Деплой 09.10.2026 17:57 МСК (Worker 498c21ee) заменил весь общий Worker старой Zoom-частью. Пользователь не менял Zoom. Это ошибка согласования исходников перед публикацией, не кэш и не ошибка пользователя.

## Восстановление

Обе истории объединены merge-коммитом, не заменой одного файла целиком. Сохраняются новые группы кнопок, спонсоры, редактирование и ✅, публикации с версиями/частями и Telegram-изменения: различение служащих, отзыв старых прав, ежедневная копия INFO в 22:50. Конфигурация и действующие секреты не откатываются; имена хранилищ, классы и миграции не меняются. Zoom sender для восстановления Worker не перезапускается.

До изменений сохранены Git-архивы и bundles обоих checkout в `AppData/Local/CodexWork`, с суффиксом `before-reconcile-20261009`.

## Защита от повторения

Production-источник — основной checkout AI-ПН, ветка main. Обе локальные копии должны быть на одном объединённом коммите. `npm run deploy:production` требует чистый коммит, обновляет origin/main и отказывается публиковать отставшую историю, проверяет Telegram и Zoom вместе. `build.command` Wrangler дополнительно требует обе исходные истории и наличие ключевых функций, в том числе при прямом вызове Wrangler из этого обновлённого checkout. Произвольный обход проверки из сторонней старой копии технически не запрещён Cloudflare; это ограничение, а не гарантия против любой ручной публикации.

Проверено перед публикацией: статические регрессии Telegram, Zoom panel, queue engine, 8 тестов библиотеки, 22 теста адресации/качества/Telegram API и 72 теста sender/control. Браузерные проверки прошли для шести панелей на ширинах 340, 420 и 1000 px: редактирование, ✅, возврат и перенос очереди, три группы кнопок, без выхода за границы. Скриншоты просмотрены. Исправлено устаревшее ожидание старого ключа coalescing в одном из автоматически объединённых тестов.

Рабочая Telegram-ветка основной папки до объединения называлась `codex/developer-full-access`, а Zoom-копия использовала `main`. После merge основная папка переводится на main fast-forward, без удаления старой ветки. Это ещё одна часть исходного расхождения.

Результат production-проверки дописывается после выполнения. Тесты Telegram используют подмены API; реальные сообщения участникам не отправляются. Деплой использует `--keep-vars`, не сбрасывая существующие переменные кабинета и секреты.
